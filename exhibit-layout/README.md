# 展場配置模擬

依「展覽空間尺寸推估圖」換算的 3D 場地（主展區約 107 m²、牆高 3.5 m），把器材清單上的台座、小盒、會議桌等以實際尺寸放進場地排展。為平板觸控設計，手機與電腦也能用。

**開啟：** https://aforesttw.github.io/exhibit-layout/

## 操作
- 左側器材清單：卡片往右拖進場地，或點一下放到畫面中央；側欄可收合
- 單指拖器材移動，拖到別的器材上方會疊放；拖旁邊的圓點旋轉（吸附時每 15°）
- 底部工具列：±15°、轉 90°、翻面（直立／側放／橫放）、複製、刪除
- 雙指捏合縮放、扭轉換角度、一起上下推改俯角
- 紅框＝超出地板或與其他器材重疊

## 存檔
- 右上「存檔」：已開啟的檔案會存成新版本；新的配置會先請你取檔名
- 「檔案庫」：大家共用的檔案清單，不用密碼。可開啟、看版本紀錄、刪除（刪掉的在「最近刪除」可以救回）
- 兩個人同時改同一個檔案時，後存的人會看到提醒，可以選「仍要存」或「另存新檔」，對方的版本都會留著
- 共用檔案庫存在 Cloudflare D1（部署方式見 [worker/README.md](worker/README.md)）；連不到時會先存在這台裝置
- 「匯出檔案」存成 .json，「匯入檔案」打開；「匯出圖片」存目前視角的 PNG

## 版本
- `index.html`：最新版（v5）
- `versions/v5.html`：v5，檔案庫拿掉「存成新版本」按鈕，避免不小心存進已開啟的檔案
- `versions/v4.html`：v4，共用檔案庫（Cloudflare D1）、存檔鈕、版本紀錄、最近刪除
- `versions/v3.html`：v3，方案可存本機、方案檔匯出／匯入、本機下載圖片
- `versions/v2.html`：v2，3D 引擎內嵌，修正 Claude App 內無法載入
- `versions/v1/`：v1，最初版

尺寸單位 cm（寬 × 深 × 高）。D13 會議桌高度、H26／H16／H17 尺寸為暫估。
