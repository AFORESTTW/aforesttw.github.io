# 展場配置模擬

依「展覽空間尺寸推估圖」換算的 3D 場地（主展區約 107 m²、牆高 3.5 m），把器材清單上的台座、小盒、會議桌等以實際尺寸放進場地排展。為平板觸控設計，手機與電腦也能用。

**開啟：** https://aforesttw.github.io/exhibit-layout/

## 操作
- 左側器材清單：卡片往右拖進場地，或點一下放到畫面中央；側欄可收合
- 單指拖器材移動，拖到別的器材上方會疊放；拖旁邊的圓點旋轉（吸附時每 15°）
- 底部工具列：±15°、轉 90°、翻面（直立／側放／橫放）、複製、刪除
- 雙指捏合縮放、扭轉換角度、一起上下推改俯角
- 紅框＝超出地板或與其他器材重疊

## 存檔
- 這個網址的方案存在**目前這台裝置的瀏覽器**（localStorage），換裝置或清除瀏覽資料就不見
- 要備份或給別人：「方案 → 匯出方案檔」存成 .json，對方用「匯入方案檔」打開
- 「匯出圖片」存目前視角的 PNG

## 版本
- `index.html`：最新版（v3）
- `versions/v3.html`：v3，方案可存本機、方案檔匯出／匯入、本機下載圖片
- `versions/v2.html`：v2，3D 引擎內嵌，修正 Claude App 內無法載入
- `versions/v1/`：v1，最初版

尺寸單位 cm（寬 × 深 × 高）。D13 會議桌高度、H26／H16／H17 尺寸為暫估。
